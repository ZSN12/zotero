参与

和我们一起把「可信」做实

这个项目不设「招聘页」——我们设参与页。开源仓库即是面试： 提交一个被合并的 PR（修一个 bug、补一个领域包、加一条评测）， 比任何简历都说明问题。

四条参与路径

🛠 开源贡献者

MIT 协议，任何背景都可参与。好的入手点：测试加固、文档勘误、 新塔型 overlay 适配（换塔只改配置的纪律见 产品能力）。 贡献约定：诚实性优先——不粉饰失败、不冒充口径。

🏗 领域包共建者

角钢塔领域包（angle-tower）是第一个实例。如果你熟悉其他工程 图纸域（桥梁 / 钢结构厂房 / 管道），六层契约模板可以直接复制—— 我们最缺「第二领域」的验证者。

🏭 工程合作与试点

有真实图纸与 BOM 数据的设计院 / 施工 / 运维单位：我们提供 全链跑批（上传 → GLB + 证据链 + 评测报告），你提供数据与 工程反馈。试点数据不出本地环境。

📐 评测与基准共建

五层口径 / 匈牙利匹配 / 容差语义都是可挑战的设计—— 认为口径不对，欢迎带论证来改。评测器是门禁不是可调参数， 改口径必须带全量回归对比。

唯一的硬门槛

诚实性契约：不粉饰失败、不冒充口径、不注入不可追溯的 「魔法数字」。见 关于页的四条铁律—— 违反任何一条，交付即无效。这一条对所有参与者同样适用。
