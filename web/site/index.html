为什么可信

🔗 三条证据链

图纸读数（SourceRef 逐实体）× BOM 交叉核验（件号/截面/数量） × 几何验证（闭环/求解/重复件号）。评测器是门禁不是可调参数。

📦 六层契约

drawing → hypothesis → rebuild → semantic-IR → validation-gate → complete-tower。每层只消费上一层产物，每层独立可跑、独立可审计。

🧾 版本指纹链

version.json 记录模型/overlay/骨架的 SHA 指纹与 GT 注入面； 产物改过后指纹不匹配 = 交付无效。

🚦 两道交付门禁

门禁 1 self_test（单测 + 内置示例端到端）；门禁 2 validate_public_ir （schema + 口径纪律 + GT 披露闭环）。红就是红，不粉饰。

一条命令换一座塔

python3 domains/angle-tower/scripts/init_domain.py ~/towers/my-tower --name my-tower
#   放图纸进 dxf/ · 填 overlay.json（字段带纪律说明）· 放 BOM
python3 domains/angle-tower/scripts/validate_workspace.py ~/towers/my-tower   # 预检
for L in 1 2 3 4 5 6; do
  python3 domains/angle-tower/scripts/run_layer.py $L --workspace ~/towers/my-tower
done

多塔泛化纪律：换塔只改配置，不改代码。详见 产品能力与开源快速开始。
