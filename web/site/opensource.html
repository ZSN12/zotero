github.com/ZSN12/engineering-trace — 领域包（domains/angle-tower）、引擎（traceability/）、测试（700+ 用例）、 CI（tests / gates / full-suite 三层）与交互式 Demo 全部开源。

5 分钟上手

git clone https://github.com/ZSN12/engineering-trace.git
cd engineering-trace
pip install -r requirements.txt -r requirements-tower.txt

# ① 两道门禁
python3 domains/angle-tower/scripts/self_test.py            # 门禁 1
python3 domains/angle-tower/scripts/validate_public_ir.py \
  examples/tower_110kv_model.json                            # 门禁 2

# ② 建一座自己的塔（工作区 → 预检 → 六层）
python3 domains/angle-tower/scripts/init_domain.py ~/towers/my-tower --name my-tower
python3 domains/angle-tower/scripts/validate_workspace.py ~/towers/my-tower
for L in 1 2 3 4 5 6; do
  python3 domains/angle-tower/scripts/run_layer.py $L --workspace ~/towers/my-tower
done

overlay.json 模板每个字段带 _doc 纪律说明； 预检对未知 GT 注入面 fail-closed（先登记再使用，防未披露注入）。

仓库结构

domains/angle-tower/     领域包：六层契约 + 两道门禁 + 工作区入口
traceability/            引擎：数据模型 / DAG / intake / solve / 评测 / 交付
schema/                  公共 IR JSON Schema（含证据层）
web/                     交互式 3D 追溯 Demo（零依赖后端 + 品牌站）
scripts/                 单塔管线入口（run_*_full.py）+ 验收脚本
examples/                内置示例（110kV 塔 + P&ID 管线）+ 各塔 GT
tests/                   700+ 用例（快层默认 / 全量见 CI）
.github/workflows/ci.yml CI：tests / gates / full-suite

贡献约定（诚实性优先）

动引擎前先过门禁

改 traceability/ 任何代码前后各跑一次 self_test.py；评测指标只从 scripts/eval_a2_profiles.py 产出，不手算。

提交带口径实测

提交信息带上口径变化（如「dual-union R 39.3%→75.8%」）； 无指标变化的改动需说明为什么不影响指标。

新增 GT 注入面必须登记

只许 z-only（层表/跨度表），严禁 x/y/拓扑；新键先登记 versioning.py，否则预检与门禁 2 都会拦。

拒绝静默失败

降级/跳过/清理必须落盘留痕（skipped_reason / 报告键）， 不允许「无声消失」。
