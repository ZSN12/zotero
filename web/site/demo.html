在线演示

三个入口，同一套证据链

本地启动 python3 web/server.py 后访问 http://127.0.0.1:8000。以下链接均在该服务下生效。

① 交互式全链 Demo（推荐）

铁塔工程追溯 Demo →

上传 DXF → 全链跑批（intake → 编译 → 验证 → 求解）→ three.js 3D 展示。点任意杆件看证据卡：SourceRef（哪张图哪个实体）、 件号/截面（BOM 交叉核验状态）、几何来源（直读/重建/参数化）。 预置模型一键载入：

  • 国网 35A1-JC1（3473 杆 / 高 36.6m / 官方全塔）
  • 35A2-ZC1 / 35A1-JC2 / 35A2-JC2（多塔泛化）
  • 110kV 猫头塔（316 杆 / 85 节点，秒级）

② 图纸 ↔ 3D 联动追溯

左 3D · 右图纸 →

点任意 3D 杆件，右侧自动翻到来源图纸并放大高亮对应实体线； 点图纸上的黄色高亮线，3D 相机反向定位杆件。证据卡带件号、 截面、几何来源与置信度——参数化补全的杆件明示「无对应图纸实体」。 国网 35A1-JC1，1007/3823 根杆可直溯到 DXF 实体级。

③ 全屏 3D 查看器

JC1 全屏查看器 →

按几何来源分色：直读（绿）/ 镜像重建（蓝）/ 拼接（黄）/ 派生（灰）， 残留复核点红球标注。支持 M1–M6 模块渐变与杆件点选。

git clone https://github.com/ZSN12/zotero.git
cd engineering-trace
pip install -r requirements.txt -r requirements-tower.txt

# 门禁 1：内置示例端到端（单测 + 冒烟 + 证据 IR）
python3 domains/angle-tower/scripts/self_test.py

# 六层逐层审计（吃刚才的产物，不重跑）
for L in 1 2 3 4 5 6; do
  python3 domains/angle-tower/scripts/run_layer.py $L --out-dir out/35A1-JC1-full-deliver
done

Demo 服务零第三方后端依赖（stdlib http.server）；评测数字与 首页基线同源（version.json 可复核）。

演示里值得看的三件事

分色 = 诚实

每根杆的颜色即其几何来源； 重建/派生杆件不会被渲染成「和直读一样」。

点选 = 追溯

点杆件弹出证据卡：源图实体、 BOM 核验状态、假设链（若有）。

红球 = 待复核

复核队列的残留悬空节点 显式标注，不静默消失。
