## 1. 问题：层位 z 值的 GT 依赖面

当前管线里所有「分段/平台/横隔」类合成器的 z 层位来自三类**GT 来源**：

| 消费点 | 现值来源 | 位置 |
|---|---|---|
| `leg_chain_stitch` 断链层 | `gt_diagonal_terminal_levels`（45 z）+ `gt_terminal_levels_override`（33 z） | tower_symmetry.py:1397 |
| 跳层对重建层集 | 同上 | tower_symmetry.py:691 |
| 横隔层 | `gt_diaphragm_levels_override`（6 z） | tower_geometry.py:1218 |
| 平台/横担层 | `use_gt_platform_levels`（15 z） | tower_symmetry.py:554 |
| 横隔合成硬编码 | `22700/22800/…`（6 个 JC1 常数） | tower_geometry.py:1218（L1 债） |

后果：④「假设可追溯」门禁被 gt_injected 披露面拖住；L1 硬编码层常数债；
换塔（ZC1）要重做全套 override 表。

**目标**：层位由 DXF 证据自推（投票），逐点替换 GT 表。与已撤回的
P2.6 span 注入的根本区别：**无塔专属常数、无 GT 反推**——每层带证据
出处（哪册哪类杆端点/哪条标注），GT 只做离线验证。

## 2. 证据源（实测盘点，JC1）

### 2.1 锚层（精确，无提取噪声）
- **A 标注层** `beam_marker_levels_mm`：图纸梁标注文本（marker 识别产物，
  recognized 证据），每册 2-12 个，JC1 合计 25 层。命中 GT platform 15/15。
- **B 册边界层** `view_regions z_offset`：图纸分册布局事实（07→7000、
  06→12000、05→16000/18000、04→24000、02→30000）。

### 2.2 几何投票端点（±100-300mm 提取噪声）
各册 front 视图提取杆件的**端点 z 直方图**（100mm 桶），按 origin 分权：

| origin | 权重 | 理由 |
|---|---|---|
| `dxf_geom` | 2 | 直读画线端点（腿线断点/斜材转折=分段边界） |
| `diag_synth` | 1 | 画线拓扑补全（纯口径已承认的图形证据） |
| `diag_complete` | 1 | 同上 |
| `leg_synth` | **排除** | 表驱动 span 产物——入投票 = GT 洗白通道 |
| `marker_synth` 杆 | **排除** | 文本证据已由锚层 A 表达，避免双计 |

### 2.3 不采纳的证据
- **尺寸标注文本**：sheet `dimensions` 实测为杆件规格（75/100/95mm），
  无标高语义，不投票。
- **GT 任何字段**：仅离线验证用（§5）。

## 3. 算法（原型实测冻结）

```
vote_level_grid(per_sheet_bars, marker_levels, z_offsets):
  # 1) 每册：端点直方图（100mm 桶 × origin 权）
  #    核桶 = ≥2 独立杆的桶（单杆桶只加权、不连链——防稀疏桥并簇）
  # 2) 核桶链：相邻核桶 gap ≤ 400mm 连链
  # 3) 链内贪心剥峰：最强核发射为层 z，±400 吸收其余核，循环
  #    （比谷分割稳：9900..11100 链剥出 9900+10700 双层）
  # 4) 锚骨架：marker(w3) + 册边界(w2)，±300 去重合并（marker 优先取值）
  # 5) 几何补位：几何层按权重降序，离骨架任一层 ≥400mm 才加入
  # 6) 输出：sorted levels + 每层 provenance（册/origin/杆数/权重）
```

关键实测教训（写死在设计里）：
- **桶均值/链式中位会把层位拉偏 100-700mm**（v2-v4 教训）：簇心必须取
  众数桶（最强核），不是均值。
- **链式 gap≤250 全糊**（7000-11400 连成 89 杆巨簇）：核桶门槛 + 400 链距。
- **±400 吸收半径**：小于最小真实层间距（14400/14500=100 允许并，
  8000/8500=500 不许吞）。

### 独有层的处置
不删除（它们是真实结构点，收腰/交叉处腿链确实断）：分级置信度
`marker > boundary > geom_w≥20 > geom_w<20`。集成时：
- **break_levels（腿链断链）**：全网格直接用（多切不亏——豁免表 P2.5
  已防误合并）；
- **合成杆 z 定位（横隔/平台）**：只用 marker+boundary+高置信几何层
  （假阳层顶多造成个别 FP，不破坏已有 TP）。

## 5. 验证方案（离线，GT 只进这里）

`scripts/validate_level_grid.py --tower jc1|zc1`：
1. 跑投票网格（真实 sheets/ 中间产物或重跑提取）；
2. 对 GT 层集合（terminal ∪ platform）算命中率（tol 150/250/300 三档）；
3. 输出分层报告：命中/未命中/独有，每层 provenance；
4. 退出码：可绘制区命中 < 85% → 1（门禁）。
报告落 `out/<tower>/level_grid_validation.json`，进交付审计链。

## 6. 集成方案（分阶段，每步全量 A/B + 红线）

| 阶段 | 替换点 | 验收 |
|---|---|---|
| D2a | `leg_chain_stitch_break_terminal` 的 break 层：`gt_terminal_levels_override` → 投票网格 | JC1 dual-pure 不回退（≥304），dual-recon ≥99% 红线，ZC1 不回退 |
| D2b | 横隔硬编码 6 常数（L1 债）→ 网格高置信层 | 同上 + 横隔 TP 数不降 |
| D2c | `panel_cross_skip_pairs` 跳层对层集 | 同上 |
| D3 | （评估后决定）`use_gt_platform_levels` → 网格 marker+boundary 层 | 需单独 A/B：平台层质量影响面大，回退则保留 GT 表并记档 |

**不改变的**：
- `metrics.py` 容差/匹配器（提分纪律）；
- 纯口径 origin 准入名单——层位来源去 GT 化不改变杆件 origin 语义
  （dia_synth 仍是 dia_synth，只是它的 z 从投票网格来）；
- `version.json` 的 `gt_injected` 披露（替换完成后逐面清零）。

## 7. 纪律边界（对照 P2.6 教训）

1. **无塔专属常数**：算法参数（桶宽 100、核门槛 2 杆、链距 400、吸收
   400、补位距离 400）是提取噪声尺度决定的一般参数，两塔共用，不按塔调。
2. **GT 只做验证**：投票内核不 import gt_profile/不读 GT 文件；验证脚本
   单独文件、单独调用。
3. **防洗白**：leg_synth（表驱动）端点不入投票——它就是被撤回的 P2.6
   的通道。
4. **每层可追溯**：网格层带 provenance 记录（哪册/哪类/几杆），交付可审计。
5. **A/B 全量**：每个集成阶段跑前后完整对比 + pytest + L1-L6 + ZC1 回归。
