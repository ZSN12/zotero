### 4.1 35A1-ZC1 分散式阶梯（2026-09-07 Phase 4 续，commit 本批）

**版式诊断**（`ladder_z.py` 分散式兜底的依据，全部实测）：
- 01-1 单线总图是「分段索引图」——H 向标注只有每站接地节拍对 (1000,2400)
  与两个分段高度 4500/6400、4000/7000，无 ZC1 式同 x 阶梯列；
- 阶梯证据分散在各分段立面自带的「段内阶梯列」：列内最大值=段高锚
  （02:5400 / 04:6500 / 05:8000 / 06:8000 / 07:4000 / 08:4500），
  其余为等节拍；相邻列错半位（05 的 800+1600×4+800 半拍列）；
- 无任何累计锚（全册最大标注值 9000），塔总高不在图纸明示。

**重建算法**（`distributed_ladder`，纯 DXF 无 GT）：
1. 每页提取 H 向阶梯列（x 容差切列 + 列和 ≥4000 + 格数 ≥2）；
2. 节拍签名去重：锚+节拍多重集相同的页视为复制视图
   （实测 07/11、10/13 互为复制，各剔一张）；
3. 剩余页按册号序自底向上堆叠（国网分段立面惯例），
   段边界=锚前缀和，junctions=各段全列累计并集平移。

**验证**（`tests/test_ladder_z_distributed.py`，8 项全绿）：
- 主链 02→04→05→06→07→08 堆叠边界
  `[0, 5400, 11900, 19900, 27900, 31900, 36400]` 对 GT 最近层偏差
  `[+1000, +1000, +500, 0, -300, -100, +100]`——塔顶 36400 vs GT 36300；
- 主链区间 GT 层位命中 31/35 = 89%（±500mm）；
- 未命中 4 层：1000/4400（接地/基础标高，图纸不在分段立面而在总图）、
  23650、34900（半节拍层）。

**已知限制（挂账）**：
- 主链截止页无独立版面信号——塔头细节页 09/10/12 仍被分配超塔高
  z 链（[36400,58800]），生产消费方需按 z_span 上界过滤；
- 锚/图高比例尺信号不可靠（主链 07=7.3 低于细节页 10=17.4），
  不能用于自动裁剪主链。
