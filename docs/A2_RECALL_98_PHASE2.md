### M1：裙底 3D 实体投影口径对称（+3 TP）

`derived_parametric_base`（extrapolate_base_segment 外推的裙底跨层大腿
+ 井字扇骨，6500→0）是全塔 3D 实体杆，但四面展开给它们带了 face 标记
（f/b/l/r），侧视投影按单面过滤被丢弃。GT 侧对应杆无 face 直接投影双视
——口径不对称。修复：将其纳入 `is_3d_recon` 双视白名单
（traceability/eval/metrics.py）。

### M2：扭结网格锚伴生源（+24 TP——双层扭转桁架突破）

GT 物理实构：17000→14400 与 17000→14500 为**双层紧邻扭转 X 桁架**
（层距 100mm）。此前扭结 X 源层取证据质心（轨迹簇 16614 + 提示簇
16871/17136 → 质心 16685），对真实锚 17000 系统性低偏 315mm：

- 源端 d1=315 时，双层弱目标（14400/14500）在 1:1 匈牙利匹配中被
  强目标挤出（cost 473 vs 301），12 根 × 双视 = 24 FN；
- 17000 锚源下 d1=0：14400↔14349（d2≈51）与 14500↔14175（d2≈347）
  双双进入容差圈。

实现（tower_geometry.py）：对每个质心源派生**网格锚伴生源**
（±500 内最近 spoke_step 网格层）——纯增量共存（第一版吸附替换质心
曾致 −81 TP 回归：网格源被 `ztw in _grid` 排除，扭结 X 全部消失；
改为伴生共存后恢复）。

### M4a：锚源目标域收紧（FP −473）

锚源此前对深度窗 [2000,3500] 内全部目标层（网格+扭结簇）生成面板；
实测锚源对网格目标的面板 0 使用（kfan/junction 链与质心源已覆盖该域）
——纯 FP。收紧为只朝扭结簇目标（`_twist_levels` 证据层位）：
TP 不变 1050，FP 3452→2979，P 23.3%→26.1%。
对照实验：全部源收紧会 −18 TP（质心源→网格目标有真实贡献），故只收锚源。
