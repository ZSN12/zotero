## 关键实现（traceability/solve/tower_geometry.py）

1. **complete_k_fan_braces（S8.1-S8.6）**：junction/twist 层位 K-fan + X 面板
   模板补全。层位来源：横隔层位 ∪ 角点轨迹 z 簇（±500 加权质心）∪
   diagonal_topology 高度提示簇（目标层 ±150 合并、>150 独立保留——「簇分裂」
   对应 GT 双层紧邻目标 14400/14500 的证据歧义）。
2. **complete_head_panel_chain（S8.4）**：塔头 z≥29500 X 面板链，锚层
   （横隔 ∪ 轨迹簇）∪ 600mm 细分；锚层平台环（角↔角面梁 ×4 + mid↔mid
   斜弦 ×4 + 通径 ×2，塔尖平台标准构型）。
3. **横隔面 mid 构件（S8.6）**：横隔环层位补 mid↔mid 斜弦 + 轴向通径
   （GT 横隔实构）。
4. **intake 顺序**：kfan/头链在 reconstruct_diagonal_topology 之后执行，
   消费 `_dt_rep` 高度聚类修正扭结层位漂移。

## 剩余 FN=48 结构（诚实记录）

- 横担桁架杆（Z≈30000-30800，双视 21）：DXF 图面该层横担外伸端 |x|≈2200
  未见提取节点（模型该区 |x|max≈1219）——属提取深度缺口，需横担模板专项。
- 17000→14500 扭结双层目标（12）：证据簇 14153/14349 对 GT 14400/14500
  偏差 250/150mm，1:1 匹配下弱目标（cost 473 vs 301）被强目标挤出。
- 塔顶小横担 33850（3）、裙部角（3，b 面口径不可见）、34200 局部（4）、
  其余散点。
