## 四、核心问题：底段不在 10-14（明确「否」）

1. **最低的 14 起始于 z=7,500**，其底宽 4314mm；底段 z=0 需要 **5524mm**，
   **短 21.9%**。方法残差仅 ±1.4%，无法弥合。
2. **全册最大横标注 = 4594mm（07 号）**，距 5524mm 差 17%。
3. 15–46 最大横标注仅 2292mm，更不可能。
4. 底段所需底宽 5524mm 对应 276.2 单位（scale 20）；全册最宽主域 07 为 229.7 单位。

→ **35A1-JC1 图册中没有任何一张图绘制 z<5,500 的塔身立面。**
→ 上一轮「底段无源」的结论**维持不变**。

## 五、10-14 的真实性质：不同呼高的「组合段上段」

五张的段高与 z 区间**全部自洽**：

```
16,000 − 7,500  = 8,500 ✓ (=14 段高)
16,000 − 10,500 = 5,500 ✓ (=13 段高)
16,000 − 13,000 = 3,000 ✓ (=12 段高)
23,000 − 15,000 = 8,000 ✓ (=11 段高)
23,000 − 18,000 = 5,000 ✓ (=10 段高)
```

结构特征：**14 ⊃ 13 ⊃ 12（同止于 16,000）；11 ⊃ 10（同止于 23,000）**——嵌套。

这符合「每个呼高把塔身切成 2 段（下段 + 上段），10-14 是各呼高的**上段**」：
- 呼高 16,000 的三种下段划分：0→7,500 / 0→10,500 / 0→13,000
- 呼高 23,000 的两种下段划分：0→15,000 / 0→18,000

**推论（存疑）**：底段应属于这些呼高的**下段**（0→7,500 等），但这些下段图纸
不在 02-46 中——本册未收录，或在别的图号/别的塔型册里。

## 六、运维建议（不改，仅供参考）

⚠️ **不要把 10-14 加进 merge_stems_extra**。
它们与 05/06/07 在 z 7,500–23,000 上**大面积重叠**，合并会产生重复杆件：
- 14 (7,500–16,000) ⊇ 06 (11,000–16,000) 全部
- 11 (15,000–23,000) ⊇ 05 (16,000–23,000) 大部分

若确实需要召回，应先做去重（按 z 区间 + 半宽指纹判重），不能整段并入。
