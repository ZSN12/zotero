### 1.2 A2 几何评测指标差异的根本归因（已实测封板）
早期文档曾误判 A2 召回率低是因为“斜材被画成了 40mm 的短碎块”。**该假设已被实测彻底推翻**，真正的四大客观差异为：

1. **图纸与 GT 的节间细分粒度不同**：
   * 图纸采用工程加工习惯，主腿为一根通长角钢（如 5013mm）；
   * GT 按照每个内部水平隔板（Diaphragm）将主腿拆分为多段。严格端点评测受长度比门禁（`length_ratio <= 3.0`）限制而无法直接配对。
2. **GT 模型包含多变体叠加（Multi-variant Superposition）**：
   * GT 在同一塔腿位置包含了多种不同角钢厚度（如 L100X7 / L100X8）的并存重叠构件，真实物理铁塔不可能同时安装多根角钢，理论召回率上限物理性 $<100\%$。
3. **底段 $Z \in [0, 5500]\text{mm}$ 立面图纸缺失**：
   * 图纸集缺失地面到 5.5 米的基础立面总图，导致该区间的 100 余根杆件在无图条件下无法通过纯识别还原。
4. **长斜材绘制表达差异**：
   * 图纸斜材多以节间短画示意，GT 则是宏观中长杆建模。

> **评测原则定论**：坚决**不向模型注入 GT 假杆、不人为放宽评测门禁**。A2 指标定位为相对基线的改进度量。

## 3. 当前待修缺陷与演进计划（Action Items）

### 3.0 A2 召回 1.9% 的精确根因（2026-08-31 实测封板，主线程 + 三子代理交叉验证）

> **本节是本轮最重要的产出**：把 A2 从「玄学低」定位到「三个可量化的精确根因」，
> 每个都有实测数据支撑。A2 目标已从「绝对 85%」修订为「相对基线改进」，但
> 相对改进的**最大单一杠杆**就是根因 1（横隔口径）。

**A2 评测口径（代码实测，非假设）**：
`eval_a2_geometry_2d` 用 `mode="recognition"`——模型侧只统计 `geometry_class=="recognized"`
的杆（513 根，全为 front 面直接识别），**排除** reconstructed（1539 根四面镜像）与
derived（496 根横隔/角腿/中心轴）。而 GT 侧 `gt_bars_2d` 是**全部 1071 根物理杆**
（含横隔 295 + 斜材 520 + 主腿 252）。**两侧口径不对称，是召回 1.9% 的第一性原因。**

**三个精确根因（GT 1071 根的构成）**：

| 根因 | GT 杆数 | 占比 | 模型现状 | 可修复性 |
| :--- | :--- | :--- | :--- | :--- |
| **① 横隔（水平）被标 derived 排除** | 295 | 28% | **模型已生成 374 根横隔**（`generate_diaphragms` 22 杆十字拓扑与 GT 完全一致，面心/内部节点误差 0-1mm），但 `face="diaphragm"` → `is_derived_bar` → 排除 | **可修（语义/口径）** |
| **② 斜材节间细分差异** | 520 | 49% | 图纸斜材通长画法，GT 按节间打断多段；严格端点+长度比门禁下无法匹配 | 需节间细分（方案 A 已实现，收益有限） |
| **③ 主腿多变体叠加** | 252 | 24% | GT 每角 8 段重叠（L100X7/X8 并存），物理不可复现 | 不可修（GT 自矛盾） |

**根因 ① 的精确证据链**：
1. `generate_diaphragms`（`tower_geometry.py:895`）**已经实现**「标准国网 22 杆双层十字横隔
   拓扑」（外框 8 + 面心-内十字 8 + 角点-内十字 4 + 内圈 2），与 GT 横隔拓扑**逐杆吻合**。
2. 从 DXF 塔腿节点（4 角，12mm 精度）推导面心 `(±half,0),(0,±half)` + 内部
   `(±half/2,±half/2)`，与 GT 横隔节点误差 **0-1mm**（z=11500/14000/16000 三水平全验证）。
3. 但横隔杆被 `face="diaphragm"` + `diaphragm=True` 标记，`is_derived_bar` 判为 derived，
   `is_physical_bar` 排除，A2 不统计。
4. **核心语义矛盾**：横隔在 GT 是**真实物理杆**（L56X4/L50X4/L45X4 角钢，295 根），
   但代码把 diaphragm 与 corner_leg/center（纯展示几何）一并归为 derived。

**模型杆件全景（2548 根）**：recognized=513（全 front）、reconstructed=1539
（b/l/r 各 513，四面镜像）、derived=496（横隔 374 + 角腿 + 中心轴）。

**决策点（需用户裁决，见 §5）**：
- A2 是否把横隔/镜像面纳入评测（`mode` recognition→physical）？
- 还是 GT 侧同步排除横隔（1071→776 根）？
- 横隔的「物理杆 vs derived」语义归属。

## 5. 待裁决决策点（2026-08-31，阻塞后续推进）

### D1：A2 评测口径（横隔/镜像面是否纳入）

**背景**：A2 用 `mode="recognition"`（只认 513 根 front 识别杆），GT 侧 1071 根全量。
横隔（295 根，模型已生成但标 derived）与四面镜像（1539 根 reconstructed）全被排除。

**选项**：
* **D1-a（推荐）**：A2 改 `mode="physical"`，纳入 reconstructed（镜像面 + 横隔）。
  代价：A2 从「识别能力」变成「识别+重建能力」；四面镜像会让模型侧从 513 → 2052 根，
  需确认镜像杆与 GT 单塔杆的正确对应（GT 单塔只有 1071 根，四面镜像会翻倍）。
* **D1-b**：保持 A2 recognition，但 GT 侧同步排除横隔（1071→776）与「非 front 可见」杆，
  使两侧口径对称。代价：GT 基准缩水，评测从「全塔」变「front 可见」。
* **D1-c**：横隔/镜像面只进 M3（3D 物理），A2 保持 recognition 不变，接受 A2 低召回为
  「识别能力」的真实反映。

### D2：横隔的语义归属（physical vs derived）

**背景**：横隔在 GT 是真实物理杆（295 根 L56X4 角钢），但代码把 `diaphragm` 与
`corner_leg`/`center`（纯展示几何）一并归为 derived。

**选项**：
* **D2-a（推荐）**：横隔改判 physical（`geometry_class="reconstructed"`，`face` 改具体面，
  保留 `diaphragm=True` 作溯源标记但不再触发 derived 排除）。`corner_leg`/`center` 仍 derived。
* **D2-b**：保持横隔 derived（维持「derived/helper 不入 P/R」的字面约束），接受横隔永久
  不进评测。

### D3：GT 注入约束的最终口径

**背景**：用户已口头「取消 GT 注入约束」，但 `docs/JC1_SINGLE_TOWER_PLAN.md` 定稿 §1.2 仍写
「坚决不注入 GT」。需明确最终口径。

**选项**：
* **D3-a**：允许「GT 拓扑（连接关系+section）注入，几何坐标从 DXF 解算」。横隔重建正是
  此路径（拓扑=正方形对称常识，坐标=DXF 腿节点推导）。
* **D3-b**：连 GT 坐标也允许（全量重建，A2 可到 ~100%）。此前已明确否决（用户选「几何从 DXF」）。
* **D3-c**：维持「不注入 GT」，A2 只做相对改进。

> **我的建议**：D1-a + D2-a + D3-a。理由：横隔是模型**已经生成**的真实杆件，只因
> 标记语义被排除；改判 physical 是「纠正口径」而非「注入 GT」。这是 A2 相对改进的
> 最大单一杠杆（+28% 的 GT 杆可进入匹配），且不违反「几何从 DXF 解算」。
